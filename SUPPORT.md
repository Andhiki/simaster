# Support

## Questions and usage help

Use [GitHub Discussions](https://github.com/Andhiki/simaster/discussions) for
questions, setup help, ideas, and general conversation. Include your operating
system, the `simaster --version` output, the exact command, and the full error
message with secrets and personal data removed.

## Bugs and feature requests

Use the issue forms:

- [Bug report](https://github.com/Andhiki/simaster/issues/new?template=bug_report.yml)
- [Feature request](https://github.com/Andhiki/simaster/issues/new?template=feature_request.yml)
- [Endpoint report](https://github.com/Andhiki/simaster/issues/new?template=endpoint_report.yml)
- [Authentication issue](https://github.com/Andhiki/simaster/issues/new?template=auth_issue.yml)

Search existing issues before opening a new one. Include the version, platform,
and a minimal reproduction. Never paste cookies, tokens, passwords, or real
student data.

## Security

Do not use Discussions or a public issue for a vulnerability. Follow
[`SECURITY.md`](SECURITY.md) and use GitHub Security Advisories.

## Response expectations

This is a volunteer project. There is no response SLA. Maintainers triage when
they can, prioritise security and data-loss issues, and may close reports that
cannot be reproduced or that fall outside the scope in
[`GOVERNANCE.md`](GOVERNANCE.md).

The latest published release is supported. Unreleased `main` is development
code; see [`SECURITY.md`](SECURITY.md) for the version policy.

## UGM account and portal problems

This project cannot reset your UGM password, unlock your account, fix the
SIMASTER portal, or intervene with UGM policy. Contact UGM's IT support for
account or portal issues. If the CLI fails because the upstream service
changed, open an endpoint report with sanitized evidence.
